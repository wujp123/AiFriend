📊 Telegram 日志配置助手

3步配置，让你的 Telegram 实时接收所有用户数据

1 创建 Telegram Bot
  1. 在 Telegram 搜索 @BotFather
  2. 发送命令：/newbot
  3. 输入 Bot 名称（如：iFriendly Logger）
  4. 输入 Bot 用户名（如：ifriendly_logger_bot）
  5. 复制获得的 Bot Token
2 获取你的 Chat ID

方法1（推荐）：

  1. 在 Telegram 搜索 @userinfobot
  2. 点击 START
  3. 复制显示的 User ID

方法2（使用频道）：

  1. 创建一个 Telegram 频道
  2. 将你的 Bot 添加为管理员
  3. 使用频道 ID（格式：-1001234567890）
3 生成配置代码
⚠️ 安全提醒：
Bot Token 是敏感信息，不要分享给他人。
如果 Token 泄露，请在 @BotFather 中使用 /revoke 命令撤销。
✅ 配置成功！
请将生成的代码复制到 telegram-logger.js 文件中。
